# C# Developer. Basic

Репозиторий с домашними заданиями, учебными материалами и проектной работой по курсу **C# Developer. Basic**.

## Структура репозитория

- Каждое домашнее задание хранится в отдельной папке.
- Название папки начинается с номера задания: `HW-01`, `HW-02` и так далее.
- Внутри папки находятся исходный код, описание задания и дополнительные материалы.

## Проектная работа

В рамках курса разрабатывается Telegram-бот «Финансовый помощник» для учёта ипотеки, кредитов, платежей и напоминаний.
